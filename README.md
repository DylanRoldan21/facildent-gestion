# Facil Dent Gestión

App de escritorio para Windows que gestiona una clínica dental: caja, cobros, gastos, precios de tratamientos, agenda de citas e historia clínica de pacientes.

## Funcionalidades
- Caja diaria con registro de cobros y gastos.
- Agenda de citas.
- Historia clínica por paciente (los pacientes no se pueden borrar).
- Acceso protegido con PIN.
- Guardado atómico de datos y respaldo automático diario en `Documentos/Facil Dent Respaldos`.

## Tecnologías
Electron · Node.js · JavaScript · HTML · CSS

## Ejecutar en desarrollo
```bash
npm install electron --save-dev
npx electron .
```
